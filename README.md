# SoundSync
Музыкальный плеер для Windows x64 и Mac с Apple Silicon (macOS 14+).

## Скачать
[Открыть последнюю версию](https://github.com/Genovide/11-11/releases/latest)

Выбери полный ZIP для своей системы. Архивы с `Update` предназначены только для обновления уже установленной полной версии.

- Windows: распакуй архив целиком, запусти `SoundSync.exe`.
- Mac: распакуй архив, один раз открой `Первый запуск.command`, затем запускай `SoundSync.app`. Приложение не нотарифицировано Apple; нативный запуск Mac пока не проверен.

Python, FFmpeg и модели синхронизации уже включены. Музыка и API-ключи в сборки не входят. Папку музыки выбираешь сам. Для AI-описания введи свой ключ OpenRouter; генерация запускается по кнопке.

## Возможности
Локальная библиотека, альбомы и артисты, SoundCloud, очередь, избранное, анимации текста, синхронизация с вокалом, визуализации и фон по цветам обложки. Проверка обновлений вручную через GitHub.

## Обновления
Закрой приложение, сделай резервную копию, следуй ОБНОВЛЕНИЕ.txt. В Windows сохраняй папку Data. Если есть сомнения, распакуй полную новую сборку отдельно.
